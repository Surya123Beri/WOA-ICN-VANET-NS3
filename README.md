
 WOA-ICN-VANET-NS3

This repository contains a baseline implementation framework for VANET routing and forwarding analysis using ns3.
 Features
 VANET topology creation
 Wireless node communication
 Neighbor discovery
 Multi-hop routing
 Comparative routing algorithms
 CSV-based metric logging
 Python graph generation

Routing Algorithms
 Random Routing
 Shortest Path Routing
 Greedy Routing
 POS Routing

 Metrics Evaluated
  Packet Delivery Ratio (PDR)
  Delay
  Hop Count
 Success Ratio

 Technologies Used
  ns3
  C++
  Python
  Pandas
  Matplotlib

 Project Structure
  `src/` → VANET simulation source code
  `results/` → Experimental CSV results
  `graphs/` → Generated performance graphs
